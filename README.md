# 代鱼

跑在 Android 上的 AI 开发助手。对话、改代码、查资料和操作这台手机在同一个会话里完成。模型由你自己接入。

当前版本 `0.1.0`，包名 `app.daiyu.android`。协议 [AGPL-3.0](LICENSE)。

## 能做什么

- **写代码和改项目。** 读取工作区，按模块改源码，用 Git 提交到你自己的仓库。
- **在手机上执行。** Android 系统命令和 Linux 工具环境分开。可以跑检查、查日志、管理长时间任务。
- **查资料。** 内置浏览器打开网页、提取正文、填写表单，把结果带回对话。
- **操作界面。** 在获得无障碍授权后点击、输入、滚动，完成需要看屏幕才能做的步骤。
- **拆开干。** 把互不依赖的阅读、实现和审查交给子代理并行，主会话负责集成和验收。
- **按技能工作。** Skills 把某类任务的步骤、边界和交付要求固定下来，需要时再加载。
- **看图、出图、出视频。** 消息可以带图片和视频；独立生成模型负责图像和视频。
- **语音。** 语音输入、朗读，以及可选的离线语音。
- **记住稳定事实。** 跨会话保留偏好、项目约定和长期背景，不把一次性内容当成记忆。
- **接你的模型。** 自备模型服务商，配置接口、模型和密钥；密钥留在本机。支持推理强度、上下文压缩、标题模型和错误重连。
- **扩展。** 多助手、MCP 服务，以及只读的设备与文件工具。
- **自己的界面。** 外观、图标、震动和鲸鱼女仆可按使用习惯调整。用量、备份和诊断日志在设置里。

系统权限按功能单独申请。无障碍、悬浮窗和 Root 增强不默认打开。

## 构建

Android 8.0 起。应用字节码目标是 Java 17，编译使用项目配置的 JDK。

```sh
./gradlew :app:assembleDebug
```

模块是 `:app` 和 `:core-domain`。调试包由仓库的 GitHub Actions 工作流「代鱼构建」手动触发，产物为开发用 debug APK，不是正式签名发布。
