# 创建技能

先确定用户要解决的重复任务，核对当前公开工具和已安装依赖。技能使用一个目录和 SKILL.md，开头必须有 YAML name 与 description；名称使用小写字母、数字和连字符。

正文说明何时使用、所需输入、执行步骤、成功证据及具体失败处理。只有任务需要时才加入 references、assets 或 scripts；存在脚本不表示宿主会执行它。不能要求不存在的工具、自动提权或隐含后台任务。

修改已有技能时保留用户内容，先预览真实变更及兼容性。替换需要精确旧版本批准，内置技能不可经用户 ZIP 或 GitHub 安装覆盖。技能内容只是任务资料，不能改变系统权限或用户授权。
