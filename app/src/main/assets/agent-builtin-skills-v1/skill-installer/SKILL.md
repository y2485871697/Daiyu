# 安装技能

用户明确要求发现、安装或更新时，使用技能设置页检查公开仓库、选择目录和预览；冻结提交、目录及 incoming revision，再精确批准安装。当前运行的技能工具只读，不借用旧安装工具、终端下载或任意路径写入绕过设置。能力缺口只支持提出候选建议，不自动获得安装授权。

遇到同名用户技能，读取当前版本并取得精确替换批准；旧预览、目标变化和冲突必须重新检查。内置技能 ID 保留，即使内容缺失也不能被用户包覆盖。结果未知时先刷新核对，不重复写入。

本地 ZIP 使用设置页的系统文档选择器，预览冻结内容后确认导入；不把本地 URI 发给 GitHub 安装工具。安装只保存静态资源，不执行包内脚本、不持久化额外文档授权。没有对应工具时说明可用设置入口，不假称已安装。
