# Agent 操作卡片 UI 接入约定

本文是聊天操作卡片的设计与源码接线交接，不是第二份重构任务清单。完成状态仍以 `docs/重构清单.md` 为准。依据代码基线 c0b78a2231c28393fefe104df73b4929ea8d748e；不修改另一 UI 会话的布局。

## 范围与现状

- 下表覆盖当前已知功能范围及用户明确要求预留的操作类别，既包含模型工具，也包含宿主动作。列出 UI 样式不等于授予模型工具权限，不因设计新增后端或扩大重构功能范围。
- 当前执行调用主要是通用 `WorkStepRow`，不是已经完成的各领域富卡片；`WorkProcessCard` 是汇总容器。图片消息、交互提问、供应商公开返回的思考/摘要有独立组件。
- 不逐个工具复制一套组件：采用通用外壳、稳定类别、按内容增强的详情区。未识别的未来工具回退通用卡，不丢消息。
- “准备执行”是阶段提示，不是工具类别。只有宿主给出明确准备阶段时才这样显示，不能把任意 PENDING 都翻译成准备执行。

## 操作类别与建议标题

以下标题是 UI 文案约定候选，不是所有标题都已接线。动作可以共用同一类卡片。

|---|---|---|---|

| skills | 查找技能、读取技能说明、读取技能资源、检查技能来源/兼容性、安装/更新/移除技能 | 技能名、来源、固定提交、摘要 | 模型目录已有 skills_list/read/read_resource；GitHub检查安装是可信管理端，其他管理动作按真实后端呈现 |
| delegation | 委派子代理、批量委派、后台委派、查询任务进度、查询/读取子代理结果 | 代理/模型、任务摘要、taskId、运行状态、结果摘要 | run_child_models/start_child_tasks 已有；结果观察目前为宿主API，未见独立模型查询工具 |
| child_control | 指导/追加子任务、暂停、继续、停止/取消、替换、失败后重新委派 | 原任务身份、目标状态、原因、真实回执 | direct_child_task支持APPEND/REPLACE/REDISPATCH；pause/resume/stop为宿主API；请求接受不等于已暂停/已停止 |
| workspace | 查看/检查任务工作区、审查改动、合并/丢弃工作区 | 项目、差异摘要、提交、审查结果 | 仅设计预留；所核新项目子任务目录未证工作区工具，不照搬当前助手平台工具 |
| terminal | 准备命令、执行命令、读取输出、向会话输入、发送中断、结束会话 | Android/Linux、身份、cwd、命令、stdout/stderr、退出码 | 已有 terminal_pty_step/read 等后端；准备文案必须源于真实状态 |

| image_read | 查看图片、读取视频封面、分析视觉内容 | 缩略图、安全名称、尺寸/时长、读取结果 | 消息图片组件已存在；通用图片读取专用工具卡未完成，不把search_media元数据当已读画面 |
| browser | 搜索网页、打开页面、读取正文、查找元素、网页点击/输入/滚动、执行脚本、截图、下载、标签管理、Cookie管理 | 域名/标题、动作、正文/截图/下载摘要 | browser_read/write及动作适配已有；Cookie值/认证数据不进入卡片 |
| gui | 查看屏幕、截图、点击、长按、滑动/滚动、输入/粘贴、系统按键、等待页面 | 应用、目标描述、动作与结果、获准截图 | GuiScreenToolFactory的screen/screen_action已有；不把网页DOM动作和手机GUI混淆 |
| apps | 查找应用、打开应用、打开链接、停止/冻结/解冻应用 | 应用名、动作、回执 | search_apps已有；写操作按当前真实授权/后端，不从类别表扩大权限 |

| system_action | 设置闹钟/计时器、调音量/媒体控制、Wi-Fi/蓝牙/系统设置、剪贴板、系统面板 | 目标值、时间、动作结果 | 逐个绑定真实系统动作；不凭卡片完成动画宣称成功 |
| generation | 生成图片、生成视频、查询生成状态、读取/下载生成结果 | 生成模型、摘要、批次数、进度、媒体结果 | generate_images/videos已有条件注册和付费批准；不重复请求付费生成 |
| speech | 朗读、语音合成/播放、语音识别/听写/转写 | 文本摘要、播放或识别状态、结果 | UI类型预留；语音功能存在不等于同名Agent工具已注册 |
| mcp | 连接外部工具、发现/刷新工具、调用MCP工具 | 服务名、工具名、参数摘要、结果 | McpRunScope有注册接缝；外部工具名称动态，必须有通用回退 |
| context | 查询上下文、检索历史、压缩上下文、读取运行状态、重连 | 范围、压缩/重连状态、摘要 | 区分运行系统事件与模型工具，不伪造一次工具调用 |

| generic | 执行其他工具 | 图标、工具显示名、摘要、状态、按需展开详情 | 未知/新增工具的强制回退，不能按白名单漏显示 |

## 跨类别的状态与内容组件

- 建议设计状态：排队、准备、执行中、等待用户、暂停中、已暂停、停止中、已停止、成功、失败、已中断、未执行、结果未确认。是否可显示某状态取决于该后端的真实事件；不同任务不必都有全套状态。
- 现有步骤枚举只有 `PENDING/OK/FAILED`；持久回执另有 `SUCCEEDED/FAILED/UNKNOWN` 等，运行状态也有停止/中断。不得仅改枚举名称就称完成接线；未知结果不画绿色成功，也不提供自动重试。
- 准备、执行中可有轻量动态效果；已结束历史行静止。展开/收起不得重发工具。
- 共用内容组件：命令与输出/退出码、文本/代码、检索命中、图片/视频、网页预览、子任务列表/结果、差异摘要、交互问答、错误摘要。
- 配套容器：工作过程总卡、模型实际公开的思考/摘要、等待用户卡、压缩/重连/中断提示。不展示未公开的模型内部推理。
- 复制/展开/查看结果与执行按钮分开。重试、继续、取消、打开页面等按钮只有确有宿主回调和当前权限时显示，历史/已过期卡不得恢复执行权。

## 源码实际接线点

根目录 `/workspace/代鱼`，包路径前缀 `app/src/main/kotlin/app/daiyu/android/`：

1. `ui/screens/chat/conversation/ChatScreenModels.kt`：WorkStepUi、WorkStepState、WorkProcessUi。
2. `ui/screens/chat/conversation/ChatTurnMapper.kt`：MessageBlock.Tool → WorkStepUi；目前name直接取invocation.name，需要集中展示映射，不改真实工具标识。
3. `ui/screens/chat/conversation/WorkProcessCard.kt`：工作过程容器和步骤外壳。
4. `ui/screens/chat/conversation/MessageContentUi.kt`、`MessageContent.kt`：图文工具混排也要使用同一新卡片分发，不只改汇总路径。
5. `ui/screens/chat/conversation/ChatMessageList.kt`：AssistantTurn实际挂载，保留历史片段、稳定key与消息顺序。
6. `ui/screens/chat/conversation/ChatScreen.kt`：ChatScreenActions；动作经既有宿主回调到MainActivity/Controller，不从Composable直接访问数据库/启动执行器。
7. `ui/RetainedToolOutcomes.kt`：持久回执的结果投影，保持owner/run/message匹配；不要根据JSON里出现error字样判断成败。
8. `QuestionCard.kt`和`ReportedReasoningCard.kt`：复用现有绑定/数据源，不另造第二套业务状态。
9. `integration/tools/RunCatalogTools.kt`：本轮可用工具注册；记忆、Skills、子任务等具体注册类在同目录。运行目录才是可用性的证据，不能拿本助手平台工具清单当新App已实现目录。

### 交给另一AI的执行要求

- 先读取daiyu-new Skill和唯一重构清单；确认新仓库main及并发文件归属。只改已协调的聊天呈现/映射/必要回调文件，不改设置布局或他人未提交内容，不建分支、不强推。
- 实现本地Android Jetpack Compose组件，不交付HTML网页、静态设计图、仅Preview或独立演示页。
- 增加集中toolName/action→展示类别/中文标题/安全摘要的映射与通用回退；如引入UiModel必须标明为新实现，保留toolCallId/owner及原始工具标识。
- 已有工具走真实MessageBlock/运行事件；未实现类别只在Preview/测试夹具中预览，不在生产聊天伪造执行记录，不为UI新增模型权限。
- 同时接通无图片工作过程和图文混排两条路径，保证同一工具不重复渲染。子任务入队和查询结果分开，子代理正常后台运行不随父回复结束假标完成。
- 参数/结果先结构化且有界摘要，敏感字段脱敏；不将Cookie、密钥、凭据、验证码全文默认显示/记录。不用字符串猜测操作成功。
- 交互回调沿用真实宿主。后端没有动作时省略按钮，不能留下看似可点击的空回调。Unknown、过期、其他owner卡禁重放；副作用/付费工具不能通用自动重试。
- 验证分类映射、未知工具回退、真实结果状态、图文顺序、历史重建、展开不执行、过期按钮失效；运行相关ChatTurnMapper与RetainedToolOutcomes测试，UI测试按项目云端流程。
- 代码与唯一清单/更新说明同次提交，给出实际diff、接入路径、运行过的命令与退出码、仍缺后端项。提交/Preview成功不等于交付验收。
