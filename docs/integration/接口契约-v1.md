发布者：1号总集成。核对基线ae6e834；本文件是可回读的接口协调记录，不是第二份功能任务清单、代码已实现声明或其它会话已确认声明。

## 已冻结，可供模块内实现遵循

1. 保留现有ModelPort/ModelSession/ToolOutput、ConversationStore和Runner构造兼容入口。transport resume只补未成功sink确认的事件，不重发模型请求或历史工具outputs。控制锁内不执行阻塞模型取消、存储或外部回调；恢复未知副作用不自动执行。
2. 批准03号提出的历史分段v1数据形状作为协作目标：MessageHistorySegment(messageId, role, blocks, protocolItems)、Message.historySegments默认emptyList、MessageHistory.expand(history)；codec encode/decode/validate，segment JSON键message_id/role/blocks/protocol。非空segments是模型历史权威顺序、display blocks仍用于聚合展示；空segments保留旧路径。该形状不是attempt/request身份，不得拿它冒充运行代际。具体可编译签名与验证约束随03成品回交核对；当前main尚无这些API，01不提前调用不存在的类。
3. 02产出真实分段；03负责DB/文本备份/ArchiveCodec/schema迁移；05消费权威历史用于Context读写/分支remap、revision/压缩边界/估算；01统一模型历史expansion入口，防止各层重复展开；18负责完整包往返。03提出schema5与可选history_segments字段，但迁移和解析器成品通过前不改主库。旧payload严格兼容；只对白名单新字段作版本明确的扩展，不改成宽松接收未知字段，旧空段archive字节/digest兼容须测试。
4. Context发送顺序：同一helper/owner executor，先prepareSend成功，再接受user/RUNNING持久回执；失败不消费草稿附件、不留下被当已执行的新请求。已有prepareSend/recordUsage/branch/revise接口沿用；01接缝前必须05交当前参数/线程/失败语义。provider usage、估算、余额各自独立。
5. 公共ChatController/MainActivity、Manifest、Gradle/依赖、workflow与状态清单仅01写；注册目录06写；ConversationDatabase/Conversation/整个ContextStorage由03写，05只交ContextStorage所需增量。媒体专属预览13、子任务弹窗12、语音14、搜索组织15、聊天宿主16各守边界，R13非自研外观不抢改。
