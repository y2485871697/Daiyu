# 单会话导出后端合同

本增量仅提供后端入口，UI 由另一路接线。不要把现有全库备份按钮改名当作单会话导出。

## 调用

`ChatController.exportConversationBackup(uri, conversationId, resolver = application.contentResolver)`

- 在主线程调用。`conversationId` 必须取自用户发起导出的那条会话，文件选择返回后仍使用原 ID，不从当前选中项重新取值。
- 沿用 `dataTask` 的恢复完成、无活动运行、无其他数据操作与未关闭门闩；不满足时同步拒绝，不打开目标 URI。
- 后端 worker 先完成选定会话的导出与校验，再以 `wt` 打开目标并写入。会话已删除/不存在或包无效时，目标不打开、不截断。
- 结果通过现有 `dataBusy`、`dataNotice` 和观察回调投递主线程；导出不增加 `dataRevision`，不改选择、草稿、配置或源消息。
- 只有成功通知才表示本次输出流写入和关闭已成功；写入或关闭失败的目标可能不完整，不应作为有效备份。UI 不以文件已存在推定成功。

## 内容与兼容性

沿用 `daiyu-neutral-complete` v1 与其中的 `daiyu-neutral-text` v1，不引入新格式、schema、导入账本或自动合并行为。

- 仅包含指定会话、其消息原始 blocks/protocol/history_segments、会话内草稿、归属该会话的 archive/branch/context_usage，以及消息附件和所引用的去重 blobs。
- 分支的 parent/through 只保留来源标识，不递归导出父会话或其他分支。
- 全局 composer 草稿固定为空，config 固定为空；不读取其他会话、全局配置或凭据。其他会话过大、坏行或缺失 blob 不阻断本会话导出。
- 原格式不包含 runtime checkpoint、当前请求 recorded usage、运行租约、系统授权或秘密；本入口不扩展这些能力，不作为运行续接文件。
- 保留原 16 MiB 文本、64 MiB blobs、112 MiB 完整包上限与原校验器；超限/缺档失败，不截断。文本导出仍受原大字段 CursorWindow 能力限制。
- 可直接通过既有 `importUserBackup(uri, complete = true)` 导入；重复包仍按原摘要幂等，身份冲突按原事务拒绝，不覆盖同名 ID，不自动发起模型或工具请求。
