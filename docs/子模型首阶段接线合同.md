# 子模型首阶段接线合同

本合同描述本批实际后端，不代表 P15/P16 整体验收完成。UI 由另一路接线；不得把普通 `send` 改成隐式启用子模型。

## 入口

- `ChatController.bindChildSavedModel(conversationId, profileId, expectedApiModel, provider)`：用户明确选择“允许该会话的该 profile 使用当前保存的端点和凭据”后调用。`expectedApiModel` 必须是模型 API 名，不是 catalog record ID。provider 是明确选择的 catalog 快照；本批不新增供应商凭据库。
- 每次重新绑定先撤销该会话/profile 旧许可，任何前置校验失败都不能复活旧许可；`revokeChildSavedModel` 可显式撤销。许可仅存在于 Controller 内存，不进备份或数据库。
- `sendWithChildren(conversation, text)`：只接受已存在会话。冻结该会话 `subagent_configuration`、profile 与保存模型设置后进入原发送/工具/持久化链。未绑定、配置或保存设置变化、配置禁用、模型策略不支持时返回 null，保留草稿，不切换到主模型。
- 普通 `send` 不注册子模型工具。仅此次显式 child 发送注册 `run_child_models`（capability `delegation.text.review`，READ_ONLY），父模型决定是否调用；开启不等于已经派发。

## 当前支持范围

- 仅启用的 text `review` profile；模型默认推理必须 OFF，不支持推理档位、媒体生成或语音 profile。GPT 速度只复用已有协议支持；冲突 custom body 在网络请求前拒绝。
- 父工具参数 `tasks:[{profile_id,prompt}]`，整批 1–8 项；每项非空 prompt 最多4096字符/16KiB UTF-8。全批校验后才入原 ToolDispatcher ledger。
- 子任务冻结 parent conversation/run/group/generation 与独立 child run/assistant message；子模型不带工具、不带写授权、不递归派发。相同 provider/API model 的 profile 共用并行池，0 表示不增加模型池限制（仍受单批8项边界）。
- 子任务真实执行结果按输入顺序返回父工具回执；子消息不混入聊天 messages，父 receipt 继续通过原消息/checkpoint链持久化。每个子任务另外保存状态与结果记录，见下节；不新增子用量、可恢复执行 checkpoint 或计费能力。
- 确认未发请求的本地失败为 NotExecuted；开始调用模型后失败/超时/停止为 Unknown，绝不自动重开或重发。收到子工具请求或超量文本即拒绝，即使 transport 吞掉回调异常也不能返回 Confirmed。
- stop/close 请求取消子模型，并等待 worker 真实退出才释放本轮资源、允许下轮发送；cancel 返回本身不代表已退出。整个批次超时120秒。

## 子任务状态与结果持久化

- `ChatController.childTasks(conversationId, limit = 20)` 读取指定会话最近1–20个任务快照，供后续保留任务面板接线。读取不发起模型请求、不授予凭据或工具权限。
- 数据库版本8新增 `child_tasks`。整批排队记录在任何 worker 请求之前同事务写入；调用模型 open 前必须提交 RUNNING，成功结果持久化后才允许父工具返回 Confirmed。记录包含父 conversation/run/message/owner、group/generation、独立child身份、profile、原任务及结果。
- 成功子任务的结果独立保存；同批其他任务失败不删除已完成记录。未发送的失败记 NOT_EXECUTED；已进入请求边界但无法确认的结果记 UNKNOWN，不自动重试。
- 写入与恢复复用原 SQLiteRuntimeStore 的 OS 租约。新 Controller 取得租约后的同一恢复事务将遗留 QUEUED 转 NOT_EXECUTED、RUNNING 转 UNKNOWN，保留 COMPLETED 和原结果；旧租约释放后不能再读写任务存储。
- 任务记录通过父 message 外键级联删除；删除父消息或会话、替换导入删除旧消息时一同清理。当前 neutral backup 仍只导出既有聊天数据，不新增任务记录备份格式；任务结果仍会随已存在的父工具回执进入原聊天备份。
- 这是状态/结果恢复，不是子任务执行恢复。面板、独立暂停/继续、跨父回复运行仍未接入。

## 尚未接入

独立后台任务面板、持久子任务恢复、跨主回复保留子任务、子任务独立暂停/继续/追加与失败重派、可执行 implementation 工具授权、媒体/推理 profile、完整子用量归属均不在本阶段。这里的同步 parent tool 不能冒充这些能力。
