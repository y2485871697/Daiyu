# 开发指南

主分支仅 `main`。新仓库使用公开 `y2485871697/Daiyu`，不继承旧历史；不创建工作树分支。

源码类/文件采用英文 PascalCase，模块/资源用小写英文；面向用户的文档和工作流名称用中文。APK命名：`代鱼-<版本>-<短提交号>.apk`。

构建工具固定：Gradle 9.8.1 / AGP 9.4.1 / Kotlin 2.4.21 / JDK27 / compileSdk37.2 / build-tools37.0.0 / cmdline-tools23.0。Wrapper JAR从已核验的官方Gradle 9.8.1发行ZIP提取；JAR与发行ZIP分别按官方SHA256校验，不使用摘要不符的tag仓库JAR。

通过 `gh workflow run build.yml --repo y2485871697/Daiyu --ref main` 触发“代鱼构建”；执行前核对是否已有运行。不在手机本地编译 APK。工作流先做边界检查、单测、Lint，再构建Debug开发APK与模拟器启动验证，产物有源码SHA和摘要。

开发debug密钥由每次CI任务临时生成；跨任务签名可能变化，不能作为稳定升级通道。S1不安装至用户手机。正式签名需后续单独确定和保管，不复制旧签名、不提交密钥。

当前没有发布许可证；不要把代码许可状态与引用的第三方组件许可混淆。

版本依据：Gradle versions/current、Google Maven和Maven Central稳定metadata、Android repository2-3.xml channel-0、Temurin27 GA release。取2026-10-13最新稳定版，排除alpha/beta/RC/EA。AGP9采用内置Kotlin，根部JVM插件2.4.21提升编译器依赖。Kotlin官方完全验证的Gradle上限可能滞后9.8.1，本项目实际组合以CI测试为门禁，不宣称全插件官方认证。模拟器google_apis x86_64/API26，google_apis_ps16k x86_64/API37.2。

构建JDK27与Android字节码目标17分别设置；前者采用最新稳定环境，后者为Android兼容目标，不是继续用JDK17编译。

## 可选电脑协作与云端回退

电脑是可选辅助节点，不是工作流依赖。当前云端单独完成领域单测、Lint、APK和API26/37.2平台测试，不注册self-hosted runner、不等待电脑、不以电脑结果跳过云端门禁。离线或SSH连接失败直接跳过电脑，沿用同一次云端运行，不重复构建APK。

电脑项目操作限于E:\daiyu及真实子目录，不安装服务、不改全局设置。现阶段只同步经过摘要核验的源码快照，使用既有JDK做环境校验。普通工作目录不是隔离：尚未建立真实执行隔离，因此不执行仓库脚本、Gradle、测试或任意runner任务。电脑测试加速仍待隔离完成后启用，当前不能声称已接通自动测试回退。

平台协议夹具使用内存HTTPS连接、合成密钥和固定Responses事件；真实请求编码、SSE解析、领域工具续轮和终态链路接受验证，但不访问真实供应商。数据库和模型设置测试仅使用测试APK自身存储，不删除目标应用聊天库或覆盖模型设置。
