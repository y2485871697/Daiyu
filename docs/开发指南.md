# 开发指南

主分支仅 `main`。新仓库使用公开 `y2485871697/Daiyu`，不继承旧历史；不创建工作树分支。

源码类/文件采用英文 PascalCase，模块/资源用小写英文；面向用户的文档和工作流名称用中文。APK命名：`代鱼-<版本>-<短提交号>.apk`。

构建工具固定：Gradle 9.8.1 / AGP 9.5.0-alpha09（用户授权预览例外） / Kotlin 2.4.21 / JDK27 / compileSdk37.2 / build-tools37.0.0 / cmdline-tools23.0。Wrapper JAR从已核验的官方Gradle 9.8.1发行ZIP提取；JAR与发行ZIP分别按官方SHA256校验，不使用摘要不符的tag仓库JAR。

通过 `gh workflow run build.yml --repo y2485871697/Daiyu --ref main` 触发“代鱼构建”；执行前核对是否已有运行。不在手机本地编译 APK。工作流先做边界检查、单测、Lint，再构建Debug开发APK与模拟器启动验证，产物有源码SHA和摘要。

开发debug密钥由每次CI任务临时生成；跨任务签名可能变化，不能作为稳定升级通道。S1不安装至用户手机。正式签名需后续单独确定和保管，不复制旧签名、不提交密钥。

当前没有发布许可证；不要把代码许可状态与引用的第三方组件许可混淆。

版本依据：Gradle versions/current、Google Maven和Maven Central稳定metadata、Android repository2-3.xml channel-0、Temurin27 GA release。取2026-10-13最新稳定版，其余工具排除alpha/beta/RC/EA；AGP为消除setVisible弃用调用，单独获准使用9.5.0-alpha09。AGP9采用内置Kotlin，根部JVM插件2.4.21提升编译器依赖。Kotlin官方完全验证的Gradle上限可能滞后9.8.1，本项目实际组合以CI测试为门禁，不宣称全插件官方认证。模拟器google_apis x86_64/API26，google_apis_ps16k x86_64/API37.2。

构建JDK27与Android字节码目标17分别设置；前者采用最新稳定环境，后者为Android兼容目标，不是继续用JDK17编译。

## 可选电脑协作与云端回退

电脑是可选辅助节点，不是工作流依赖。当前云端单独完成领域单测、Lint、APK和API26/37.2平台测试，不注册self-hosted runner、不等待电脑、不以电脑结果跳过云端门禁。离线或SSH连接失败直接跳过电脑，沿用同一次云端运行，不重复构建APK。

电脑以E:\daiyu为主工作区，不安装服务、不改全局设置。经审阅的单测和Lint允许在现有账户下运行，不以缺少系统级沙箱为停止条件；源码快照逐文件核对SHA-256。文件优先放在根内，确因工具要求不能合理重定向的项目相关根外写入已获授权，但必须记录具体路径、工具、必要原因、操作与实际结果、证据和保留/清理状态，并向用户汇报；不访问无关个人数据，不做破坏性覆盖或认证/安全变更。工作目录、任务图门禁与缓存重定向不是操作系统沙箱。

平台协议夹具使用内存HTTPS连接、合成密钥和固定Responses事件；真实请求编码、SSE解析、领域工具续轮和终态链路接受验证，但不访问真实供应商。数据库和模型设置测试仅使用目标进程下测试专用命名存储，不删除目标应用聊天库或覆盖模型设置。

## 受限电脑协作与云端并行检查

电脑性能优先承担单测与增量检查；GitHub负责交付APK与模拟器回归，不启动本地模拟器、不新增系统驱动或服务。优先复用根内JDK/SDK、Gradle缓存和daemon，启用parallel、build-cache及按实际CPU/内存选择的workers，不并发争写同一项目目录、不反复clean。必要根外写入按前述规则汇报。

同一代鱼构建工作流新增mode=checks，仅在ubuntu-26.04和windows-latest并行执行领域单测、Lint、独立边界、shell语法，无assemble/package/签名/模拟器，不产APK，成功时定向确认模块build目录无安装包。检查与mode=build使用不同concurrency组，互不取消/阻塞，run/attempt/source_sha分别记录。默认build保留完整云端交付路径；不能拿电脑报告跳过云端自身门禁。windows-latest是GitHub托管节点，不是用户电脑，也不表示电脑自动协作已接通。检查SDK由固定setup-android action在两平台统一安装，包路径保持斜杠；Python边界检查显式读取UTF-8。

工具链用最新稳定且经实际验证的固定版本，不使用动态latest依赖；AGP9.5.0-alpha09为用户明确批准的单项预览例外，其他工具仍用稳定版；API26仍是最低兼容门禁，不因追新删除。仅工作流/文档变化不把已有电脑APK冒充新提交构建；保留原APK SHA及精确源码记录。电脑历史构建仅作为旧检查证据保留，不作为交付来源；checks模式不执行平台回归。

Ubuntu托管节点固定为ubuntu-26.04（x64，2026-09-17已GA），避免ubuntu-latest自动迁移提示与混用操作系统版本。固定OS版本线不冻结GitHub每周镜像更新；保留显式JDK/SDK工具链和KVM配置。Windows标签不变。

协作入口由daiyu-new Skill维护：`scripts/pc-checks.ps1`先preflight检查任务图，再运行`:core-domain:test`与`:app:lintDebug`，禁止APK/模拟器任务；`scripts/pc-dispatch.py`从唯一凭据文件内存认证、逐项回收报告并核对SHA-256。每次检查记录完整源码SHA、attempt、真实退出码、命令、配置与缓存基线；write-policy.json区分计划/观察到的根外写入与观测范围。配置与工具日志不是全系统写入追踪，空列表不等于整个系统绝无根外写入。已有源码快照的检查缓存可以复用，不接受不同SHA的成功报告。

AGP预览例外依据：官方9.5发布说明Issue #565740572，9.4.1的BasePlugin.kt:362在创建Android JDK image configuration时调用isVisible=false，9.5.0-alpha09已删除。使用--warning-mode=all验证，不屏蔽日志、不修改第三方JAR；电脑单测/Lint检查不替代GitHub交付包及双API回归。

## 持久协作链路

协作入口和Skill现纳入本仓库：`scripts/cooperation/cooperate.py`、`skills/daiyu-new/SKILL.md`，不再依赖会话Skill虚拟目录中的脚本。完整用法及边界见仓库Skill。证据放仓库外；`run`同步准确git archive快照、电脑逐项检查/回收、掉线仅补缺项；`offline`重新验摘要与终态，不联网。云端checks支持scope=unit/lint/all、expected_sha、唯一check_id，build必须明确mode=build；不会因补检启动APK或模拟器。已有电脑单测覆盖功能性领域单测，Linux/Windows云端兼容矩阵仍按workflow自身门禁执行，不冒称电脑报告证明Linux兼容性。
