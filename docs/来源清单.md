|---|---|---|
| 本工程源码、资源、工作流 | 本次从空目录独立编写 | 尚未选择发布许可证；临时图标为新绘制 |
| Gradle Wrapper | 官方 gradle/gradle v9.8.1，脚本与JAR | Apache-2.0；仅构建工具，许可见 THIRD_PARTY/gradle-LICENSE |

依赖更新必须同步精确版本和来源。严格clean-room没有被承诺：此前调查看过旧系统，本工程不直接复制其源码/资源。公开前静态边界检查不是法律来源独立认证。

## CI 工具（固定提交）

GitHub actions/checkout、setup-java、upload-artifact、download-artifact；gradle/actions；android-actions/setup-android；ReactiveCircus/android-emulator-runner，均固定到工作流中的完整提交号。它们只在CI运行，不打入应用；许可分别以对应固定提交的 LICENSE 为准（GitHub actions/gradle actions主要为MIT，Android工具Actions按各仓库许可）。更改提交时同步审核来源及动作权限。

JUnit的传递测试依赖包含Hamcrest Core 1.3（BSD-3-Clause）；不打入应用。Gradle官方脚本的原版权/许可头保留。


M0新增代码独立编写，使用Android公开平台API（HTTPSURLConnection、SQLiteOpenHelper、Android Keystore、ACTION_BATTERY_CHANGED、原生View），无新增生产依赖。Responses协议依据官方公开文档：
- https://developers.openai.com/api/reference/resources/responses/methods/create
- https://developers.openai.com/api/reference/resources/responses/streaming-events
- https://developers.openai.com/api/docs/guides/function-calling
- https://developers.openai.com/api/docs/guides/conversation-state

仅实现首个文本与函数调用闭环；未复制旧协议实现、提示词或测试。平台测试使用Android test.runner/base系统测试库。
