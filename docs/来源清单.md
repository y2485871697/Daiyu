## CI 工具（固定提交）

GitHub actions/checkout、setup-java、upload-artifact、download-artifact；gradle/actions；android-actions/setup-android；ReactiveCircus/android-emulator-runner，均固定到工作流中的完整提交号。它们只在CI运行，不打入应用；许可分别以对应固定提交的 LICENSE 为准（GitHub actions/gradle actions主要为MIT，Android工具Actions按各仓库许可）。更改提交时同步审核来源及动作权限。

### UI 保留原则

- 保留我们的视觉样式、主题、布局、导航、交互、流式展示、缓存和性能优化及其测试；不因所在旧文件属于 Eta 就整页或整组件废弃。
- UI 底层若含 Eta 实现，替换底层或增加必要独立接口，保持已有自研表现与行为；不默认退回新工程的临时原生启动壳作为最终 UI。
- 第三方 UI/Markdown/图标/字体组件按实际来源保留并维护许可，Eta 原作者新增的封装/算法与我们的增量分别处理。
- 按“保留的自研 UI 改动—第三方组件—待替换 Eta 片段—依赖适配—原有测试/视觉验收”登记迁移，来源核验不等同重做设计。

新 `ChatRunner` 接线处理正文 delta 与累计 final快照：相同快照不重复计数，前缀增长只检查后缀，真正纠正按最新本轮文本重建；跨item不重置。判退化先取消连接、拒绝该事件，统一FAILED及固定提示，保留已保存文本/工具结果，不自动重试。sticky标记防模型适配器吞异常后误完成或执行pending工具。
