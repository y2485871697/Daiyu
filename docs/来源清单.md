# 来源清单

| 项目 | 版本/来源 | 许可/用途 |
|---|---|---|
| 本工程源码、资源、工作流 | 本次从空目录独立编写 | 尚未选择发布许可证；临时图标为新绘制 |
| Gradle Wrapper | 官方 gradle/gradle v8.13.0，脚本与JAR | Apache-2.0；仅构建工具，许可见 THIRD_PARTY/gradle-LICENSE |
| Gradle发行包 | 官方services.gradle.org，8.13 | 构建工具；distributionSha256Sum固定 |
| Android Gradle Plugin | Google Maven 8.13.2 | Apache-2.0；构建工具 |
| Kotlin Gradle插件/标准库 | Maven Central 2.2.21 | Apache-2.0；编译工具及运行库 |
| JUnit | Maven Central 4.13.2 | EPL-1.0；仅测试依赖（含其传递测试依赖） |
| Android平台API | Android SDK API36 | Android公开平台接口；不复制平台实现 |

依赖更新必须同步精确版本和来源。严格clean-room没有被承诺：此前调查看过旧系统，本工程不直接复制其源码/资源。公开前静态边界检查不是法律来源独立认证。

## CI 工具（固定提交）

GitHub actions/checkout、setup-java、upload-artifact、download-artifact；gradle/actions；android-actions/setup-android；ReactiveCircus/android-emulator-runner，均固定到工作流中的完整提交号。它们只在CI运行，不打入应用；许可分别以对应固定提交的 LICENSE 为准（GitHub actions/gradle actions主要为MIT，Android工具Actions按各仓库许可）。更改提交时同步审核来源及动作权限。

JUnit的传递测试依赖包含Hamcrest Core 1.3（BSD-3-Clause）；不打入应用。Gradle官方脚本的原版权/许可头保留。
